ISSUE DESCRIPTION:
────────────────────────────────────────────────────────────────────────────
The depthai-ros BasaltVIO node crashed with "AddressSanitizer: attempting 
double-free" errors in the ImgFrame destructor after running for a few minutes.

Root Cause:
- The stereoCB() callback thread received ImgFrame shared_ptrs from the message 
  queue and held onto them while processing pixel data
- Meanwhile, the device input thread (XLinkInHost) was releasing its reference 
  to the same frames
- When both threads' reference counts reached zero concurrently, the destructor 
  was called twice on the same ImgTransformation object inside the ImgFrame
- This caused a "double-free" error in ImgTransformation's std::vector cleanup

THE FIX:
────────────────────────────────────────────────────────────────────────────
File: /media/logic/USamsung/depthai-core/src/basalt/BasaltVIO.cpp
Lines: 171-188

Key changes:
1. Extract ALL needed data from imgFrame BEFORE releasing it:
   - Timestamp → int64_t (primitive copy)
   - Width, height → size_t (primitive copies)
   - Exposure → chrono duration (primitive copy)
   - Pixel data → vector copy (srcData = imgFrame->getData())

2. Call imgFrame.reset() IMMEDIATELY after data extraction
   - This decrements the shared_ptr refcount while no other thread is modifying it
   - Prevents concurrent destruction attempts

3. Continue processing on COPIED data, not original frame
   - All pixel manipulation happens on srcData, not imgFrame

WHY IT WORKS:
────────────────────────────────────────────────────────────────────────────
Before fix:
  Device thread    │    stereoCB thread
  ─────────────────┼──────────────────────
  Release ref  ←───┼─── Still accessing frame
               │   Decrement refcount
               ├───→ Refcount→0, delete ImgFrame
               │    ImgTransformation destructor runs
               │    
               │     Still using frame data...
               │     Destructor runs AGAIN when callback ends
               │     Double-free! ❌

After fix:
  Device thread    │    stereoCB thread
  ─────────────────┼──────────────────────
                   │ Extract data + copy
                   │ imgFrame.reset() ←────── Release immediately
  Refcount→0       │ (imgFrame not accessed)
  Delete ImgFrame  │
  Destructor runs  │ Process copied data
  Cleanup complete │ (no more imgFrame refs)
  
  No concurrent access = No race condition = No double-free! ✅
